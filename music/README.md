沒有專屬歌曲的球隊（例如 MLB 多數球隊、NPB、日本、多明尼加、波多黎各、墨西哥、義大利）統一播 ARASHI〈Five〉官方 MV 的副歌（只循環「重播次數最多」的 0:51–1:20，不從頭播）。要換歌：編輯 `index.html` 裡 `YT_TRACKS` 的影片 ID（網址 `watch?v=` 後面那串）。
若影片被擁有者關閉嵌入、或沒有網路，會自動改播生成的節奏。

## 用自己的音檔（優先於 YouTube）

遊戲在某隊**進攻**時會循環播放該隊的音樂。

- 把你**有權使用**的音檔放在這個資料夾，檔名用「隊名.mp3」，遊戲就會自動改播它。
- 找不到檔案、也沒有專屬歌曲時，播預設歌曲（ARASHI〈Five〉的副歌）；沒有網路或影片無法播放時，才改播程式生成的節奏。
- 右上角 ♪ 按鈕可開關，設定會記住。
