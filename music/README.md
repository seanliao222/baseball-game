# 球隊進攻音樂 / Team offense music

遊戲在某隊**進攻**時會循環播放該隊的音樂。

- 把你**有權使用**的音檔放在這個資料夾，檔名用「隊名.mp3」，遊戲就會自動改播它。
- 找不到檔案時，會播放程式生成的原創應援節奏（每隊音高與節奏略有不同）。
- 右上角 ♪ 按鈕可開關，設定會記住。
