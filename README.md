# ⚾ 實況野球 — MLB × NPB × CPBL × WBC

> **打開網頁，就能在電視轉播般的 3D 球場裡，指揮你最愛的球隊拿下勝利。**

從中華職棒、日本職棒、美國大聯盟到世界棒球經典賽，58 支球隊、上千名球員全部到齊。你可以投出一顆 160 公里的直球三振大物打者，也可以在滿壘兩出局把球轟出全壘打牆；想看歷代名將同場較勁，還有中職 OB 明星隊等你挑戰。

免下載、免安裝，電腦和手機都能玩，還能用 QR code 和朋友連線對戰。

**[▶ 立即開始遊戲](https://seanliao222.github.io/baseball-game/)**

## 為什麼好玩

- **像看轉播一樣**：3D 球場、外野大螢幕、打者特寫、投手背後視角，全壘打和精彩守備都有專屬鏡頭。
- **真的在比拚能力**：每位球員有自己的巧打、力量、跑速、守備，每位投手有自己的球速、控球和球種組合，名將和新人打起來不一樣。
- **投打都由你決定**：自己選球種、瞄準、控制力量，打擊要抓時機，還能擺短棒、強振、盜壘。
- **球隊最齊全**：台灣、日本、美國的職業球隊與國家隊一次收齊，想怎麼配對都行。

## 功能

- **投球**：球種輪盤、瞄準、力量條、牽制
- **打擊**：時機條、觸擊（B）、強振（V）、盜壘
- **規則**：好壞球、界外、盜壘、雙殺、犧牲飛球、保送、觸身球、暴投、失誤、延長賽、提前結束
- **球員能力**：巧打、力量、跑速、肩力、守備、選球、彈道；投手有球速、控球、體力、多種球種
- **打線編輯與換人**：賽前調整打序和守位，賽中可換投手與守備
- **難度**：簡單、普通、困難；局數可選 3 / 5 / 7 / 9 局
- **戰績紀錄**：勝投、敗投、救援、勝利打點、全壘打、MVP，歷史戰績保存在瀏覽器
- **連線對戰**：兩人各選一隊，一人投球、一人打擊
- **手機支援**：觸控操作

## 球隊（共 58 隊，每隊 25 人名單）

選隊畫面有四個分頁：

- **CPBL 中華職棒**：中信兄弟、統一獅、樂天桃猿、富邦悍將、味全龍、台鋼雄鷹，以及 **中職OB明星隊**
- **NPB 日本職棒**
  - 中央聯盟：讀賣巨人、阪神虎、中日龍、廣島鯉魚、養樂多燕子、橫濱 DeNA
  - 太平洋聯盟：軟銀鷹、日本火腿、歐力士、羅德海洋、西武獅、樂天金鷲
- **MLB 美國職棒**（30 隊）
  - 美聯東區：洋基、紅襪、藍鳥、金鶯、光芒
  - 美聯中區：守護者、老虎、皇家、雙城、白襪
  - 美聯西區：太空人、運動家、水手、遊騎兵、天使
  - 國聯東區：大都會、費城人、勇士、馬林魚、國民
  - 國聯中區：小熊、釀酒人、紅雀、紅人、海盜
  - 國聯西區：道奇、教士、巨人、響尾蛇、洛磯
- **WBC 經典賽**：中華、日本、韓國、澳洲、美國、多明尼加、波多黎各、墨西哥、義大利

MLB 30 隊使用 2026 例行賽最後一天的現役名單與成績（資料來源：MLB 官方 Stats API）；球速、控球、球種等沒有公開數據的能力值為依成績推算。NPB 的名單和能力值為估算，可能與現實陣容不同。每隊另有廖宣皓、廖宣瑜兩位替補（右打，能力 A/B 級），不佔 25 人名額。
