# ⚾ 實況野球 — MLB × NPB × CPBL × WBC

瀏覽器棒球遊戲，Three.js 3D 轉播視角加 2D 電視 HUD。免安裝。

**[▶ 開始遊戲](https://seanliao222.github.io/baseball-game/)**

## 功能

- **投球**：球種輪盤、瞄準、力量條、牽制
- **打擊**：時機條、觸擊（B）、強振（V）、盜壘
- **規則**：好壞球、界外、盜壘、雙殺、犧牲飛球、保送、觸身球、暴投、失誤、延長賽、提前結束
- **球員能力**：巧打、力量、跑速、肩力、守備、選球、彈道；投手有球速、控球、體力、多種球種
- **打線編輯與換人**：賽前調整打序和守位，賽中可換投手與守備
- **難度**：簡單、普通、困難；局數可選 3 / 5 / 7 / 9 局
- **戰績紀錄**：勝投、敗投、救援、勝利打點、全壘打、MVP，歷史戰績保存在瀏覽器
- **連線對戰**：兩人各選一隊，一人投球、一人打擊
- **手機支援**：觸控操作

## 球隊（共 58 隊，每隊 25 人名單）

選隊畫面有四個分頁：

- **CPBL 中華職棒**：中信兄弟、統一獅、樂天桃猿、富邦悍將、味全龍、台鋼雄鷹，以及 **中職OB明星隊**
- **NPB 日本職棒**
  - 中央聯盟：讀賣巨人、阪神虎、中日龍、廣島鯉魚、養樂多燕子、橫濱 DeNA
  - 太平洋聯盟：軟銀鷹、日本火腿、歐力士、羅德海洋、西武獅、樂天金鷲
- **MLB 美國職棒**（30 隊）
  - 美聯東區：洋基、紅襪、藍鳥、金鶯、光芒
  - 美聯中區：守護者、老虎、皇家、雙城、白襪
  - 美聯西區：太空人、運動家、水手、遊騎兵、天使
  - 國聯東區：大都會、費城人、勇士、馬林魚、國民
  - 國聯中區：小熊、釀酒人、紅雀、紅人、海盜
  - 國聯西區：道奇、教士、巨人、響尾蛇、洛磯
- **WBC 經典賽**：中華、日本、韓國、澳洲、美國、多明尼加、波多黎各、墨西哥、義大利

MLB（洋基、道奇除外）與 NPB 的名單和能力值為估算，可能與現實陣容不同。每隊另有廖宣皓、廖宣瑜兩位替補（右打，能力 A/B 級），不佔 25 人名額。

## 檔案

```
index.html      遊戲邏輯、HUD、球隊名單
stadium3d.js    3D 球場、球員、鏡頭
music/          各隊應援曲
```

修改 `stadium3d.js` 後，記得更新 `index.html` 裡 `stadium3d.js?v=` 的版本號。
